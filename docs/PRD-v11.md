# PRD-v11：智能化与个性化

> 创建时间：2026-08-10
> 基线：PRD-v8~v10 全部完成
> 目标：让 APP 从"被动管理"走向"主动服务"——基于用户行为智能推荐、自动整理

## 1. 智能相册

### 1.1 自动分类相册
- 后端新增 GET /api/media/auto-albums：基于 EXIF 时间/位置/类型自动生成"智能相册"
  - "2026年春节"（日期范围+高频拍摄）
  - "海边"（GPS 聚类）
  - " screenshot 专辑"（文件类型+尺寸比）
  - "Live Photo 合集"（is_live_photo=true）
- 前端相册页新增"智能相册"Tab，展示系统自动生成的分类

### 1.2 人物去重（非人脸识别）
- EXIF 中可能有 "Camera Owner" / "Artist" 字段
- 按拍摄设备分组："iPhone 拍的照片" / "相机导入"
- 不做 AI 人脸识别（PRD-v8 §5 已排除），仅元数据维度

## 2. 存储智能管理

### 2.1 存储趋势预测增强
- 后端 /api/media/storage-forecast 已有
- 前端新增"存储健康仪表盘"：预测曲线 + 配额预警 + 建议清理项
- 当预测 30 天内将满 → 主动通知 + 推荐清理大文件

### 2.2 智能归档
- 后端 /api/media/archive-suggest 已有
- 前端"归档建议"卡片增强：展示"90天未访问"的照片列表 + 一键归档
- 归档 = 移到冷存储目录 + 标记 archived=true + 列表不展示但可搜索

## 3. 个性化体验

### 3.1 首页个性化仪表盘
- 后端 /api/media/media-personalized-dashboard 已有
- 前端首页顶部展示：问候语 + 今日统计 + 那年今天入口 + 存储概览
- 根据时间段调整问候（早上好/下午好/晚上好）

### 3.2 照片故事
- 长按照片 → BottomSheet 展示"照片故事"
- 自动生成描述："2026年8月10日 下午3点 · 在上海 · iPhone 15 Pro拍摄"
- 有 EXIF 的额外展示参数（光圈/快门/ISO）
- 背景音乐推荐（如有 Live Photo）

## 4. 离线增强

### 4.1 离线缓存策略升级
- 当前离线缓存 60 项缩略图
- 新增"离线收藏"：收藏的照片自动全分辨率离线缓存
- 离线状态下优先展示收藏 + 最近查看

### 4.2 离线编辑队列
- 离线时照片编辑（裁剪/旋转/滤镜）存入队列
- 网络恢复后自动上传编辑结果
- UIPendingOfflineQueueDialog 已有，增强为支持编辑操作

## 5. 非目标
- 不做 AI 人脸识别/场景分类（需 ML 模型）
- 不做视频自动剪辑
- 不做端到端加密

## 6. 优先级

P0（用户可直接感知）:
- §1.1 智能相册（自动分类）
- §3.1 首页个性化仪表盘

P1（存储健康）:
- §2.1 存储趋势预测增强
- §2.2 智能归档

P2（精细化）:
- §3.2 照片故事
- §4.1-4.2 离线增强
- §1.2 人物去重
