# PRD-v10：社交化与智能——从工具到平台

> 创建时间：2026-08-10
> 基线：PRD-v8 全功能 + PRD-v9 体验打磨完成
> 目标：让 APP 从"好用的个人媒体管理器"升级为"可分享、可协作、有温度的媒体平台"

## 问题诊断

当前 APP 功能完整且体验流畅，但以下场景缺失使其停在"单机工具"层面：
- 分享链接没有外部预览页——收件人点开是 JSON 或 404，必须装 App 才能看
- 没有照片地图——有 GPS 数据但无法可视化"我的照片在哪里拍的"
- 没有回忆推送——"那年今天"只在 insights 里静态展示，不会主动触达
- 多设备实时同步靠轮询——新增/删除照片要等下次 manual refresh
- 分享管理零散——创建了分享但没有"我的分享"管理页

## 1. 分享外部预览页

### 1.1 后端分享预览 HTML
- GET /s/{token} 返回轻量 HTML 页（非 JSON API）
- 页面：照片瀑布流 + 下载原图按钮 + 分享信息（创建时间/有效期/有无密码）
- 密码保护的分享：先弹密码输入框，验证后才展示内容
- HTML 内联 CSS（不依赖 CDN），~5KB，首屏 <100ms
- 响应式：手机竖屏单列，平板双列，桌面三列
- 后端已有 /api/media/share/stream/{token}/{mediaId} 流式读取，预览页直接调

### 1.2 分享管理页
- App 内新增"我的分享"入口（设置 → 分享管理）
- 列表：分享标题/缩略图/创建时间/访问次数/有效期/状态(有效/过期)
- 操作：复制链接/查看预览/撤销分享/延长有效期
- 后端已有 share-analytics + share-expiring 端点，前端补管理 UI

## 2. 照片地图

### 2.1 地图视图
- 新增 Screen.PHOTO_MAP（Tab 栏或设置入口）
- 后端新增 GET /api/media/geo-clusters：返回 [{lat,lng,count,thumb_url}] 聚类点
- 前端用 OSM 地图（KMP 兼容，不依赖 Google Maps）
- 聚类点显示数字 badge + 点击展开该位置的缩略图列表
- 底部 BottomSheet 展开当前位置所有照片的横向滚动条

### 2.2 拍摄地点时间线
- 地图视图切换到"时间线"模式：按拍摄月份在地图上画连线
- 展示"我的足迹"——哪天去了哪里，拍了什么

## 3. 主动回忆推送

### 3.1 回忆通知
- 后端新增 cron-like 检查：每天 9:00 扫描"那年今天"照片
- 有内容时推送本地通知（Android NotificationManager / iOS UNUserNotificationCenter）
- 通知点击 → 直接打开 MemoryDetailScreen 该月视图
- App 内"回忆设置"：可调推送时间/关闭

### 3.2 首页回忆卡片增强
- 现有回忆卡片只在云端 Tab 顶部展示
- 增强：全屏横滑浏览回忆照片 + 背景音乐选项
- 自动播放幻灯片 + Ken Burns 效果（缓慢缩放平移）

## 4. 实时同步

### 4.1 WebSocket 推送通道
- 后端新增 GET /api/sync/ws（JWT 认证后升级 WebSocket）
- 推送事件：media_added / media_deleted / media_updated / album_changed
- 前端 WebSocket 连接 + 自动重连（指数退避）
- 收到事件 → 增量拉取 /api/sync/changes → 更新本地列表
- 替代当前全量轮询 sync/changes，延迟从分钟级降到秒级

### 4.2 多设备状态可见
- 后端已有 device register/list 端点
- App 内"设备管理"页：显示在线设备 + 最后同步时间
- 新设备首次登录通知（安全感知）

## 5. 体验精细化

### 5.1 照片详情面板增强
- 预览底栏"详情"按钮已有 ModalBottomSheet 需求
- 内容：EXIF 完整信息 + 地图小图(如有 GPS) + 标签 + 相册归属 + 操作历史
- 地图小图点击 → 跳转照片地图(§2)

### 5.2 批量操作体验
- 多选底栏增加"添加标签"入口（现有 BatchTagDialog → 迁移 BottomSheet）
- 多选"移动到相册"
- 多选"下载到本地"

## 6. 非目标
- 不做人脸识别/AI 场景分类（需 ML 模型部署，超出范围）
- 不做视频转码/压缩（仅裁剪）
- 不做 Web 端管理界面（ops-server admin 够用）
- 不做端到端加密（增加复杂度，目标用户不需）

## 7. 优先级

P0（用户可感知的核心缺失）:
- §1.1 分享外部预览页
- §3.1 回忆通知推送

P1（平台化关键）:
- §4.1 WebSocket 实时同步
- §1.2 分享管理页

P2（体验加分）:
- §2.1 照片地图
- §3.2 回忆卡片增强
- §5.1 详情面板增强
