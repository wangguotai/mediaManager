# 一刻相册 5 功能 Tab 结构对照（真机截图 + qwen 逐屏分析）

> 来源：物理机(23127PN0CC)真机逐 tab 截图 + qwen 视觉逐屏结构化分析（2026-08-13 晚）。
> 截图：`docs/yike-profile/tab_{photo,album,find,creative,camera}.png`（私有数据，不入库）
> 用途：作为我们 media-manager 对齐一刻相册 UI 的唯一切实依据，**纠正此前把"查找"聚合误套到"照片"Tab 的方向错误**。

---

## 重要纠正（此前搞错的关键点）

- **照片 Tab ≠ 智能聚合页**。一刻相册照片 Tab 是**时间线网格**（年份大标题 + 按月分组 + 按时间|按相册切换），顶部叠加 广告Banner + 备份/清理功能卡 + 本机/云空间切换。
- **智能聚合（人物/足迹/事物/类型）是"查找"Tab 的内容**，不是照片 Tab。此前我们把人物/足迹/事物塞到了照片首页，方向错了。

---

## 一、照片 Tab（时间线）

从上到下：
1. 状态栏
2. 活动 Banner（影视剧照横幅，"《我的鸵鸟先生》邀你合影" + 右侧 搜索🔍/红包/头像 三图标）
3. 功能卡：左"22个文件待备份 开启备份"卡 + 右"17.5MB 文件清理"卡
4. 视图切换："本机 / 云空间"（纯文字，选中黑）
5. 年份大标题"2026年" + 右侧"按时间 | 按相册"（选中黑/未选灰）
6. 时间线网格（每月代表图 + 月份数字，如"4 八月"/"8 七月"/"1 六月"）
7. 底部导航 5 tab

---

## 二、相册 Tab

从上到下：
1. 顶部备份告警条("22个文件待备份 开启备份") + 搜索/金币/头像
2. 活动 Banner（"夏日出逃计划 赢2000元旅行金 去看看"，海滩图）
3. 智能搜图成册行：
   - 左：具体相册卡"夏日记忆"（配图 + "暑期|62张照片"）
   - 右：浅蓝圆角"智能搜图成册"卡，内 3 个白胶囊：个人证件卡片 / 手机截屏 / 一日三餐
4. 云空间相册：新建相册 + 按编辑时间
5. 相册列表卡（含图 + 标题 + "xx | N张照片"）
6. 筛选标签 全部/我的/共享
7. 底部 5 导航

---

## 三、拍摄（居中凸起大按钮 → 相机）

- 点凸起大按钮 → 进入系统相机 **CameraHomeActivity**（真拍照）。
- 需接入 Android 相机/权限，拍完入库。

---

## 四、查找 Tab（智能聚合【注意：这才可能是我们需要的聚合内容】）

从上到下：
1. 顶部提醒条：22个文件待备份 / 搜索 / 面包 / 头像
2. 人物：横排圆形头像（多个人物）
3. 足迹：地图大卡 + "点亮地图"蓝胶囊按钮 + 统计（旅程照片144 / 城市6 / 国家1）
4. 事物：横向滚动卡片（风景/美食/玩乐/智慧记录）
5. 类型：卡（截图12 / 动态照片1）
6. 底部提示条

---

## 五、创意 Tab（工具）

从上到下：
1. 工具网格 2行4列（时光足迹/人像美颜/AI消除 等 8 个）
2. 两个大按钮："AI改图" / "导入图片"
3. 推荐内容流
4. 底部导航

---
