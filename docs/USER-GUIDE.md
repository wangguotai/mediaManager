# 用户使用手册（USER-GUIDE）

> 受众：终端用户（用 App 存照片、看照片的人）
> 这份文档尽量不用技术术语。遇到"服务端/后端"这种词，就当成"你的云盘所在的那台机器"。
> 配套：让帮你装好的人给你一个**地址**和一个**账号密码**。

---

## 一、10 分钟跑通（第一次用）

前置：帮你装好的人已经给了你两样东西：

1. **服务端地址**，像 `https://media.example.com` 或 `http://192.168.31.251:8080`
2. **账号和密码**（如果是首次安装，他会从启动日志里给你一个一次性 token，或一个初始密码）

### 步骤

1. **打开 App** → 出现登录页。
2. **填地址**：在"服务端地址"里填上面给你的地址（带 `http://` 或 `https://`，带端口就带端口）。
   - 如果对方给你一个**二维码**，直接点"扫码登录"扫一下，地址和账号会自动填好。
3. **填账号密码** → 点"登录"。
4. 登录成功 → 进入主页，看到三个标签页：**本地相册 / 已上传 / 网盘图片**。
5. 点底部"**我的**" → "**云相册自动备份**" → 打开"自动备份新增图片"开关。
   - 默认"仅 WiFi 备份"是开的，避免吃你的手机流量。想要充电才备份也可以打开"仅充电备份"。
6. 拍一张新照片，等 15～30 秒（锁屏不打开 App 也会自动传，Android 约 15 分钟、iOS 看系统调度）。
7. 切到"**已上传**"标签 → 看到刚才那张照片已经出现在云端。

成功标志："已上传"里能看到刚拍的照片；换另一台手机登录同一个账号也能看到。

> 第一次登录后，**请立刻改密码**：在"我的"里找"修改密码"，输旧密码 + 新密码（至少 8 位）。如果是用一次性 token 登录的，更要先改密再正常用。

## 二、三个标签页说明

主页顶部有三个 Tab（标签页），底部还有"我的"。

### 2.1 本地相册（第一个 Tab）

- 显示**这台手机**上的相册照片和视频。
- 单击一张 → 全屏预览。视频会自动播放。
- 长按一张 → 进入"选择模式"，可以一次选多张。
  - 选完后底部出现按钮：**全选 / 分享 / 删除 / 上传**。
  - 点"上传"把选中的传到云端。
- 顶部有**搜索图标**：点开输关键词（文件名/日期），300ms 后自动过滤。

> 本地相册是"源"，云相册是"备份后的结果"。开了自动备份后，新照片会自动从本地相册传到云端。

### 2.2 已上传（第二个 Tab）

- 显示**已经传到云端**的照片和视频，按拍摄日期分组。
- 这是你"云相册"的样子。换一台手机登录同账号，看到的就是这些。
- 滑到底会自动加载更多（无限滚动）。
- 单击预览、长按多选，和本地相册一样。
- 预览界面可以**编辑**（裁剪/旋转/滤镜）、**收藏**（点星标）、看 **Live Photo 动态照片**（有按钮播放嵌入视频）。

### 2.3 网盘图片（第三个 Tab）

- 显示服务端 `cloud-images` 目录里的**共享图片**（公共图库，所有人都能看，不按用户隔离）。
- 一般由帮你装服务端的人往那个目录放图片。
- 用法和已上传类似，但你不能删这里的图（只有管理员能）。

### 2.4 我的（底部导航）

- **后端地址配置**：换服务端地址。
- **主题**：System / Light / Dark / AMOLED。
- **云相册自动备份**：详见 §三。
- **文件管理**：详见 §四。
- **相册管理**：创建/查看云端相册（把照片归到自定义相册）。
- **修改密码 / 退出登录**。

## 三、自动备份（云相册自动备份）

这是最重要的功能：开了之后，新拍的照片自动传到云端，不用手动操作。

### 3.1 打开自动备份

"我的" → "云相册自动备份" → 打开"**自动备份新增图片**"开关。

- **默认是关的**，需要你主动打开（避免没经过你同意就上传）。
- 打开后 App 会自动注册一个"设备"到服务端，之后新照片会自动传。

### 3.2 仅 WiFi 备份（默认开）

- **打开**（默认）：只在 WiFi 下备份，**不会吃手机流量**。这是和小米相册一样的默认行为。
- 关掉：移动数据下也会备份（小心流量用超）。

### 3.3 仅充电备份（默认关）

- 打开：只在充电时备份，电池供电时不传（省电）。
- 关掉（默认）：WiFi 下就能传，不要求充电。

### 3.4 视频也会备份吗？

会。照片和视频都会自动备份（大文件走流式上传，不会卡）。

### 3.5 备份状态在哪看？

- 通知栏会显示"备份中 N/M · 已暂停（非 WiFi）"之类的进度。
- 设置页显示"待备份 N 项""上次备份时间"。
- 如果卡住了，看 §六排障。

### 3.6 删了照片想重新备份？

如果你在云端删了一张照片，又在本地相册重新触发它备份，**它会再次出现在云端**（后端检测到是同一张图会"复活"记录，不会因为之前删过就永远跳过）。这是正常行为。

### 3.7 弱网/断网怎么办？

- 断网时上传会进入"离线队列"，等网络恢复后自动重传，不丢任务。
- 杀掉 App 进程再开，队列里的任务会继续重放完成。

## 四、文件管理（下载/删除/用量）

"我的" → "文件管理"。

### 4.1 查看云端全部文件

列出云端所有文件，按类型/时间排序，可以搜索。

### 4.2 批量下载

- 长按多选 → 点"**下载**"，把选中的照片/视频下载回**本地相册**。
- 可以选"原图"或"仅缩略图预览"（省流量）。
- 下载完会在手机相册里出现。

### 4.3 批量删除

- 长按多选 → 点"**删除**"。
- 删除是"软删除"：云端标记为已删，两台手机都会同步消失。
- 删除后如果想恢复，需要管理员在服务端处理（普通用户无法自助恢复，删除前确认）。

### 4.4 用量查看

- 文件管理页顶部显示"已用空间 / 总文件数"。
- 也可以在"我的"里看存储用量统计（调 `/api/sync/usage`）。

### 4.5 收藏与相册

- 预览一张图时点**星标** → 收藏（收藏列表在"我的"里看）。
- "相册管理"里可以**新建相册**（比如"旅行 2026"），把照片归进去。相册是云端的概念，多端同步。

## 五、多设备同步

### 5.1 两台手机看到一样的照片

只要**同一账号**登录到**同一个服务端**，两台手机的"已上传"标签看到的内容一样。

### 5.2 增量同步

- App 每次打开（或后台周期）会问服务端"上次同步后有哪些变化"。
- 服务端返回新增/删除/修改的清单，App 据此更新本地视图。
- 用一个"游标"记录上次同步到哪里，下次接着拉，不重复不遗漏。

### 5.3 在 A 机删了，B 机会同步删除吗？

会。删除是"墓碑"（软删除），同步到 B 机后 B 机的"已上传"里也会消失。

### 5.4 在 A 机传了，B 机多久能看到？

- B 机下次打开 App 或后台同步周期触发时看到。
- 后台周期：Android 约 15 分钟（WorkManager），iOS 看系统调度窗口。

### 5.5 最多几台设备？

没有硬上限，但每台设备会注册一个 device_id，服务端按用户隔离数据。同一账号多设备共存正常。

## 六、排障（不同步、备份卡住）

### 6.1 新照片没自动传到云端

| 检查 | 怎么做 |
|---|---|
| 自动备份开关开了吗 | "我的"→"云相册自动备份"→"自动备份新增图片"是否打开 |
| WiFi 条件满足吗 | "仅 WiFi 备份"开着的话，移动数据下不会传；连 WiFi 后会继续 |
| 充电条件满足吗 | "仅充电备份"开着的话，没充电不会传 |
| 服务端地址对吗 | "我的"→"后端地址配置"，确认地址能访问 |
| 服务端活着吗 | 让帮你装的人检查 `healthz` |
| 网络通吗 | 试着手动在"已上传"下拉刷新，看是否报错 |
| iOS 后台被系统杀了 | iOS 后台备份依赖系统调度，把 App 留在前台一会儿或等系统窗口 |

### 6.2 两台手机内容不一样

- B 机打开 App 手动下拉刷新一次。
- 确认两台登录的是**同一个账号**、**同一个服务端地址**。
- 确认 A 机那张照片确实已传到云端（A 机"已上传"里能看到）。
- 还不一致：让帮你装的人查服务端 `sync/changes` 是否正常（见 `RUNBOOK.md`）。

### 6.3 备份卡住不动

- 看通知栏/设置页"待备份 N 项"是否在减少。
- 如果一直不减：关掉自动备份再打开，触发重新检查。
- 杀掉 App 重开（离线队列会重放）。
- 大视频上传慢正常，耐心等；流量不够切 WiFi。
- 服务端磁盘满了会让上传失败，让管理员清空间。

### 6.4 登录不上

- 地址填错（少了 `http://`、端口错）。
- 账号密码错，或被限速（同 IP+用户名 1 分钟试错超 10 次会锁 1 分钟，等一会儿再试）。
- 服务端没开或地址变了，问帮你装的人。

### 6.5 预览大图闪退/OOM

- 大图（几十 MB）预览时内存不够。App 已做降采样（长边限制 2048px），理论上不会 OOM。
- 如果还闪退：重启 App；或让管理员看服务端日志（见 `RUNBOOK.md` §OOM）。

### 6.6 视频缩略图/首帧不显示

- 服务端可能没装 ffmpeg（视频缩略图靠它抽第一帧）。
- 让管理员装 ffmpeg（容器镜像已含，裸机需 `apt install ffmpeg`）。

### 6.7 删除的照片又出现了

- 这是"复活"机制：删除后如果在本地相册又触发同图备份，后端秒传命中会恢复记录。
- 想彻底删除：不要在本地相册再保留那张图，或让管理员在服务端物理清理。

## 七、小贴士

- **第一次用先改密码**，尤其是一次性 token 登录的。
- **仅 WiFi 备份**建议常开，省流量。
- **充电时备份**能让备份更积极（系统更允许后台跑）。
- **换手机**：新手机装 App、登录同账号，云端照片会自动同步下来。
- **服务端地址换了**：在"我的"→"后端地址配置"里改，不用重装 App。
- **退出登录**不会删云端数据，只是这台手机不再同步。

遇到这手册没覆盖的问题，把现象告诉帮你装服务端的人，他可以查 `RUNBOOK.md` 排障。
