## doc-sprint 任务计划

### DS-01: 图片编辑完善
**优先级**: P1
**参考**: 小米相册编辑 → 裁剪/旋转/滤镜

- 裁剪框可拖拽调整大小（四角 + 四边 handle）
- 旋转：90° 步进按钮
- 基础滤镜：原图 / 黑白 / 暖色 / 冷色（ColorMatrix 实现）
- 保存到相册（本地）+ 可选上传后端
- 编辑后原文件保留，保存副本

**验收标准**:
1. 打开编辑 → 裁剪框可拖拽 → 裁剪后预览正确
2. 旋转 90° 三次回到原图方向
3. 滤镜实时预览
4. 保存成功 → 新图片出现在相册
5. 取消编辑不修改原文件

### DS-02: 批量操作增强
**优先级**: P1
**参考**: 小米相册选择模式

- 选择模式底部栏：全选/分享/删除/上传（本地 Tab）
- 批量删除确认对话框
- 批量上传进度条
- 批量分享走系统分享 Intent
- 选择模式下单击选/取消 + 数字实时更新
- 选择模式有选中指示器（✓ 覆盖在缩略图上）

**验收标准**:
1. 长按进选择模式 → 底部栏显示
2. 选 3 张 → 批量删除 → 确认 → 删除成功 → 列表更新
3. 选 2 张本地 → 批量上传 → 进度条 → 完成提示
4. 全选 → 数量 = 当前列表总数
5. 取消全选 → 数量归零 → 退出选择模式

### DS-05: 性能优化
**优先级**: P2

3. 内存占用稳定 < 200MB
4. 分页加载无空白闪烁
