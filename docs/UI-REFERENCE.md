## 一、整体风格基调

一刻相册整体采用 **浅色、圆角卡片、低饱和灰蓝** 风格：

- **背景**：浅灰白（约 `#F5F5F7`），内容承载用白色圆角卡片（`RoundedCornerShape` 约 12~16dp）
- **主强调色**：蓝色（选中态 Tab / 主按钮 / 筛选高亮），约 `#3478F6`
- **营销/活动色**：红橙色渐变（Banner、红包图标）
- **文字层级**：主标题加粗黑色、二级灰字 `onSurfaceVariant`
- **状态栏**：跟随内容（浅色底 → 深色时间）

> 我们现有 AiTabs/MediaListScreen 用 Material3 + emoji + 纯文本标题，功能已齐全，但缺「卡片化、分组化、视觉层级」。本文档给出可落地美化建议。

## 二、照片 Tab（照片时间线）— 对照 `MediaListScreen.kt`

### 一刻相册结构
```
[状态栏]
[推广 Banner（可关/可跳）]
[快捷入口横排: 🔍搜索 | 🧧活动 | 👤头像]
[切换栏: 本机 | 云空间]
[筛选: 按时间 | 按相册]
[年份标题: 2026年]
[月份分组网格: 每月代表缩略图 + 序号"8 八月"]   ← 2列
[底部 4-Tab 导航]
```

### 设计要点（可直接借鉴）
1. **照片网格按月分组**：每月「代表缩略图 + 月份序号」，而非纯平铺。我们 MediaListScreen 已按日期分组，可强化为`%，大月份数字视觉。
2. **顶部告警条**（"N 个文件待备份"）可做胶囊提示置顶。
3. **筛选切换（按时间/相册）**：用 pill 或分段控件，高亮选中。

## 三、相册 Tab — 对照 `AiTabs.kt` 的 `AlbumTabScreen`

### 一刻相册结构
- 告警条 / 入口
- 营销 Banner
- 「一键创建相册 >」入口
- **智能搜图成册** 大卡片组：个人证件卡片 / 手机截屏 / 一日三餐（AI 语义自动成册）
- **云空间相册**：新建相册 + 按编辑时间排序
- **筛选标签**：全部/我的/共享 + 新增
- 底部导航 + 右上搜索/更多

### 差距与建议（把「智能相册」做起来）
我们目前 `AlbumTabScreen`：
- 标题「相册」28sp 加粗 → 建议改为「智能相册 · 按场景」大卡片网格 + 人物聚类圆形头像横排（一刻相册的横排头像 + 「更多」模式）。
- 缺「新建相册/共享」筛选标签 → 可加一行 pill（全部/我的/共享）+「+新建」。
- 缺「AI 语义成册」一键 → 我们已有 `/api/ai/albums` 自动场景，可对上「智能搜图成册」。

## 四、查找 Tab（智能查找）— 对照 `AiTabs.kt` 的 `FindTab`
```
一级分区（纵向滚动）：
  人物：横向圆形头像列表 + 右侧「更多 >」
  足迹：大地图卡片 +「点亮地图」按钮 + 统计（旅程145 | 城市6 | 国家1）
  事物：风景 / 美食 两个方块卡片
  类型：动态照片 等
  顶部：搜索框（智能提示）+ 告警条
```
设计要点：
- 「人」用**圆形头像横排**，右上「更多 >」；我们 `getPersons()` 已支持，把 ClusterAvatar 卡片改横拉。
- 「事/足迹」用**地图/照片大卡**；我们有 `geo 聚类` + `PhotoMapScreen`，可合成「点亮地图」卡片。

### 五、创意 Tab（工具）— 对照 `AiTabs.kt` 的 `CreateTab`
```
2x4 图标网格（两排）：
  时光足迹 / 人像美颜 / AI消除 / AI动图
  创意拼图 / 一键成片 / 朋友圈9图(New) / 全部工具
两个大操作按钮（橙色行动）：
  [AI改图⚡] [导入图片+]
下方：推荐内容流
```
设计要点：工具用**图标+文字 2 行 4 列**网格，比我们的 list 更漂亮；「AI改图」橙色主按钮可作我们 AI 检索/编辑统一入口。

### 六、搜索页（照片→右上🔍）— 对照 AI 搜索 UI
```
顶：返回 < + 灰底搜索框（智能文案）「这个角度真不错 👍」
分区：
  回忆 破卡片（带日期 + 生成的一句话）
  人物 横排圆形头像（人脸聚类）
  地点 横向缩略图
```
设计要点：搜索框下方「回忆/人物/地点」分区卡片，比单一列表丰富；可直接对 `/api/ai/search` 的类别结果建模。

## 八、落地顺序建议（T0->N）
1. 底部导航 4-Tab 高亮 + 图标统一，即时观感提升。
2. 相册 Tab 场景/人物「大卡片 + 横排圆头像」。
3. 增加「按时间/按相册」+ 筛选 pill。
4. 统一圆角 + 浅灰背景。
5. 搜索页分区（回忆/人物/地点）。

> 后端能力已就绪，主做前端 Compose 布局重构（`AiTabs` 内专项）。是否按此顺序开工，或优先某一项，等你拍板。
